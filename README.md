# 커피 룰렛

항목을 입력하고 돌려서 무작위로 하나를 선택하는 간단한 웹 룰렛 앱입니다. (예: 오늘 커피를 살 사람 뽑기)

## 실행 방법

빌드 도구도, 서버도 필요 없습니다. **`index.html` 파일 하나**에 화면·스타일·동작 로직이 모두 들어있어서, 이 파일만 있으면 어디서 열어도 그대로 실행됩니다. 더블클릭으로 열거나, 카카오톡·메일 등으로 `index.html`만 보내서 스마트폰에서 열어도 동일하게 동작합니다.

`manifest.json`, `sw.js`, `icons/` 폴더는 앱을 스마트폰 홈 화면에 "설치"할 수 있게 해주는 선택적 파일입니다 (아래 "홈 화면에 앱처럼 설치하기" 참고). 이 파일들이 없어도 `index.html`은 그 자체로 완전하게 동작합니다.

## 사용법

1. 화면 아래쪽 "카테고리 보드"에서 모든 카테고리와 그 하위 항목을 한눈에 볼 수 있습니다. 각 카테고리는 하나의 카드(컬럼)로 표시되며, 맨 오른쪽 "+ 카테고리 추가" 카드로 새 카테고리를 만듭니다.
2. 각 카테고리 카드 하단의 입력창에 이름을 입력하고 Enter(또는 "+" 버튼)로 그 카테고리에 항목을 추가합니다.
3. 카테고리 이름, 항목 이름, 그리고 화면 상단의 제목·부제목은 모두 ✎ 버튼으로 수정할 수 있습니다. 카테고리와 항목은 ✕ 버튼으로 삭제하며, 삭제 전에는 항상 "정말 제거하시겠습니까?" 확인 창이 뜹니다.
4. 각 항목 앞의 체크박스로 "이번 룰렛에 포함할지"를 정합니다. 체크된 항목은 카테고리가 달라도 모두 하나의 룰렛에 합쳐집니다 (예: 사업팀 김사원 + 홍보팀 박팀장 + 디자인팀 유사원).
5. 카테고리 카드와 카드 안의 항목은 각각 ⋮⋮ 손잡이를 드래그해 순서를 바꿀 수 있습니다. 드래그가 어려운 환경(특히 스마트폰)을 위해 ◀▶(카테고리)·▲▼(항목) 버튼으로도 같은 순서 변경이 가능합니다.
6. 포함된 항목이 2개 이상이면 "돌리기" 버튼이 활성화됩니다. 룰렛은 돌릴 때마다 4~6초 사이의 회전 시간과 기준 속도의 0.8~1.2배 사이의 회전 속도가 무작위로 정해집니다.
7. 회전하는 동안 포켓이 지나갈 때마다 째깍이는 소리가 점점 느려지고, 멈추면 색종이 효과와 짧은 팡파레가 재생됩니다. 결과는 화면 최상단 배너에 "카테고리 이름" 형식의 큰 글씨로 표시됩니다.
8. 화면은 항상 다크 테마로 고정되어 있습니다 (기기의 라이트/다크 설정과 무관).

## 당첨 횟수

- 각 항목 아래에 "최근 일주일/한달 내 당첨 횟수"가 표시됩니다. 룰렛이 멈출 때마다 당첨된 항목에 당첨 시각이 기록되고, **지금 시각 기준 최근 7일 / 28일(4주)** 안에 들어오는 기록만 집계됩니다.
- 집계는 "오늘 기준 며칠 전"으로 계산하므로 시간이 지나면 자동으로 줄어듭니다. 예를 들어 9월 7일에 당첨된 기록은 9월 14일까지는 일주일 횟수에 포함되고, 9월 15일이 되면 일주일 횟수에서 빠집니다 (28일 횟수에는 10월 5일까지 남습니다).
- 앱을 켜 둔 채로 날짜가 바뀌어도, 화면을 다시 볼 때(앱으로 돌아올 때)와 10분마다 횟수를 다시 계산해 최신 상태로 맞춥니다.
- 화면 오른쪽 위에 고정된 "당첨횟수 초기화" 버튼으로 모든 기록을 0회로 되돌릴 수 있습니다 (확인 창에서 "초기화"를 눌러야 실행됩니다).
- 바로 아래 "당첨횟수 복구" 버튼은 마지막 초기화 직전의 기록을 되돌립니다. 되돌릴 기록이 없으면 비활성화됩니다.

## 저장과 기기 간 공유

카테고리·항목·당첨 기록·제목 설정은 **브라우저의 localStorage**에 저장되어 새로고침해도 유지됩니다. 다만 이는 "그 브라우저 안"에만 저장되는 것이라, 다른 스마트폰이나 다른 브라우저에서 열면 당첨 기록이 보이지 않고 별도로 시작됩니다 — 서버가 없는 순수 정적 페이지이기 때문입니다.

기기 간에 데이터를 옮기려면 화면 왼쪽 위의 **내보내기 / 가져오기**를 사용하세요.

- **내보내기**: 누르면 "내보내기 / 공유" 창이 열립니다.
  - **정보 파일 내보내기 (.json)**: 현재 카테고리·항목·당첨 기록·제목 설정을 `roulette-backup-YYYY-MM-DD.json` 파일로 다운로드합니다.
  - **인스타그램 공유 / 디스코드 공유**: 제목·룰렛·당첨자·날짜가 담긴 1080×1080 결과 이미지를 만들어 공유합니다. 휴대폰에서는 시스템 공유 시트가 열려 인스타그램·디스코드 등 설치된 앱을 고르면 됩니다. (웹 페이지에서 특정 앱에 직접 게시하는 것은 브라우저 보안상 불가능해서, 공유 시트를 거치는 방식이 표준입니다.)
  - **결과 텍스트 복사**: 결과 문구를 클립보드에 복사합니다. 디스코드 등에 바로 붙여넣기 좋습니다.
  - 공유 시트를 지원하지 않는 환경(대부분의 PC 브라우저)에서는 결과 이미지를 자동으로 저장하고 문구를 클립보드에 복사한 뒤, 앱에서 직접 올리도록 안내합니다.
- **가져오기**: 내보낸 `.json` 파일을 다른 기기·브라우저에서 선택하면 (덮어쓰기 확인 후) 현재 데이터를 그 파일 내용으로 교체합니다.

이 방식은 실시간 동기화는 아니고, 내보낸 시점의 스냅샷을 수동으로 옮기는 방식입니다. 여러 기기가 항상 같은 당첨 기록을 실시간으로 공유하게 하려면 Firebase·Supabase 같은 공유 백엔드를 추가해야 하며, 이는 계정 생성과 별도 설정(그리고 무료 한도를 넘으면 비용)이 필요한 별개의 작업입니다.

## 모바일 지원

반응형 레이아웃으로 스마트폰에서도 사용할 수 있습니다. 터치 환경에서는 버튼이 자동으로 더 크게 표시되고, 카테고리·항목 순서 변경은 드래그 대신(또는 드래그와 함께) ◀▶ · ▲▼ 버튼으로도 가능합니다 (HTML5 드래그 앤 드롭은 터치에서 동작하지 않는 경우가 많습니다).

스핀이 진행되는 동안에는 결과가 어긋나지 않도록 편집·삭제·포함 여부 변경이 잠시 잠깁니다.

### 홈 화면에 앱처럼 설치하기

이 저장소를 GitHub Pages 등 웹 서버로 올려서(즉 `http://`나 `https://` 주소로) 열면, 스마트폰에서 "홈 화면에 추가" 기능으로 진짜 앱처럼 설치할 수 있습니다 — 아이콘이 생기고, 주소창 없이 전체 화면으로 열리며, 오프라인에서도 실행됩니다.

- **Android(Chrome)**: 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"
- **iOS(Safari)**: 공유 버튼 → "홈 화면에 추가"

`index.html`을 파일로 직접 열었을 때(주소창이 `file://`로 시작할 때)는 브라우저 보안 정책상 이 설치 기능과 오프라인 캐시(서비스 워커)가 동작하지 않습니다 — 이 경우에도 앱 자체는 정상적으로 동작하며, 단지 "설치" 절차만 웹 호스팅이 필요합니다.
