# 룰렛

항목을 입력하고 돌려서 무작위로 하나를 선택하는 간단한 웹 룰렛 앱입니다.

## 실행 방법

별도의 빌드 도구 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 사용법

1. 화면 아래쪽 "카테고리 보드"에서 모든 카테고리와 그 하위 항목을 한눈에 볼 수 있습니다. 각 카테고리는 하나의 카드(컬럼)로 표시되며, 맨 오른쪽 "+ 카테고리 추가" 카드로 새 카테고리를 만듭니다.
2. 각 카테고리 카드 하단의 입력창에 이름을 입력하고 Enter(또는 "+" 버튼)로 그 카테고리에 항목을 추가합니다.
3. 카테고리 이름, 항목 이름, 그리고 화면 상단의 제목·부제목은 모두 ✎ 버튼으로 수정할 수 있습니다. 카테고리와 항목은 ✕ 버튼으로 삭제하며, 삭제 전에는 항상 "정말 제거하시겠습니까?" 확인 창이 뜹니다.
4. 각 항목 앞의 체크박스로 "이번 룰렛에 포함할지"를 정합니다. 체크된 항목은 카테고리가 달라도 모두 하나의 룰렛에 합쳐집니다 (예: 사업팀 김사원 + 홍보팀 박팀장 + 디자인팀 유사원). 현재 룰렛에 포함된 전체 목록은 화면 중앙의 "룰렛 적용 항목"에서 확인하고 ✕로 바로 뺄 수 있습니다.
5. 카테고리 카드와 카드 안의 항목은 각각 ⋮⋮ 손잡이를 드래그해 순서를 바꿀 수 있습니다. 드래그가 어려운 환경(특히 스마트폰)을 위해 ◀▶(카테고리)·▲▼(항목) 버튼으로도 같은 순서 변경이 가능합니다.
6. 포함된 항목이 2개 이상이면 "돌리기" 버튼이 활성화됩니다. 룰렛은 돌릴 때마다 4~6초 사이의 회전 시간과 기준 속도의 0.8~1.2배 사이의 회전 속도가 무작위로 정해집니다.
7. 회전하는 동안 포켓이 지나갈 때마다 째깍이는 소리가 점점 느려지고, 멈추면 색종이 효과와 짧은 팡파레가 재생됩니다. 결과는 화면 최상단 배너에 "카테고리 이름" 형식의 큰 글씨로 표시됩니다.
8. 화면 왼쪽 중앙의 스피커 아이콘으로 음소거를, 세로 슬라이더로 전체 음량을 조절할 수 있습니다. (화면이 좁은 스마트폰에서는 휠과 겹치지 않도록 돌리기 버튼 옆 가로 슬라이더로 자동 전환됩니다.)

## 당첨 횟수

- 각 항목 아래에 "최근 일주일/한달 내 당첨 횟수"가 표시됩니다. 룰렛이 멈출 때마다 당첨된 항목에 당첨 시각이 기록되고, 최근 7일/30일 기준으로 집계됩니다.
- 결과 배너 아래 "당첨횟수 초기화" 버튼으로 모든 기록을 0회로 되돌릴 수 있습니다 (확인 창에서 "초기화"를 눌러야 실행됩니다).
- 바로 옆 "당첨횟수 복구" 버튼은 마지막 초기화 직전의 기록을 되돌립니다. 되돌릴 기록이 없으면 비활성화됩니다.

## 저장과 기기 간 공유

카테고리·항목·당첨 기록·제목·음량 설정은 **브라우저의 localStorage**에 저장되어 새로고침해도 유지됩니다. 다만 이는 "그 브라우저 안"에만 저장되는 것이라, 다른 스마트폰이나 다른 브라우저에서 열면 당첨 기록이 보이지 않고 별도로 시작됩니다 — 서버가 없는 순수 정적 페이지이기 때문입니다.

다른 사람들과 당첨 기록을 실시간으로 공유하려면 다음 중 하나가 필요합니다.

- **공유 백엔드 추가**: Firebase, Supabase 같은 서비스에 당첨 기록을 저장하고 모든 기기가 그 데이터를 읽고 쓰도록 바꾸는 방법입니다. 실시간으로 잘 동기화되지만, 별도 계정 생성과 약간의 설정, 그리고 (무료 한도를 넘으면) 비용이 들 수 있습니다.
- **수동 내보내기/가져오기**: 버튼으로 현재 상태를 파일이나 코드로 내보내고, 다른 기기에서 그 파일을 불러오는 방식입니다. 실시간 동기화는 아니지만 서버 없이 구현할 수 있습니다.

어느 쪽이 필요하신지 알려주시면 그에 맞게 구현해 드리겠습니다.

## 모바일 지원

반응형 레이아웃으로 스마트폰에서도 사용할 수 있습니다. 다만 카테고리·항목 순서 변경의 드래그 앤 드롭은 마우스 기반 API라 터치에서는 동작하지 않을 수 있어, 터치에서도 동작하는 ◀▶ · ▲▼ 이동 버튼을 함께 제공합니다.

스핀이 진행되는 동안에는 결과가 어긋나지 않도록 편집·삭제·포함 여부 변경이 잠시 잠깁니다.
