# 커피 룰렛

항목을 입력하고 돌려서 무작위로 하나를 선택하는 간단한 웹 룰렛 앱입니다. (예: 오늘 커피를 살 사람 뽑기)

**바로 열기 → https://leesh0424.github.io/roulette/**

## 실행 방법

빌드 도구도, 서버도 필요 없습니다. **`index.html` 파일 하나**에 화면·스타일·동작 로직이 모두 들어있어서, 이 파일만 있으면 어디서 열어도 그대로 실행됩니다. 더블클릭으로 열거나, 카카오톡·메일 등으로 `index.html`만 보내서 스마트폰에서 열어도 동일하게 동작합니다.

`manifest.json`, `sw.js`, `icons/` 폴더는 앱을 스마트폰 홈 화면에 "설치"할 수 있게 해주는 선택적 파일입니다 (아래 "홈 화면에 앱처럼 설치하기" 참고). `sheet-sync.gs`는 구글 시트로 기록을 공유하고 싶을 때만 쓰는 파일입니다 (아래 "동료들과 당첨 기록 공유하기" 참고). 이 파일들이 없어도 `index.html`은 그 자체로 완전하게 동작합니다.

## 사용법

1. 화면 아래쪽 "카테고리 보드"에서 모든 카테고리와 그 하위 항목을 한눈에 볼 수 있습니다. 각 카테고리는 하나의 카드(컬럼)로 표시되며, 맨 오른쪽 "+ 카테고리 추가" 카드로 새 카테고리를 만듭니다.
2. 각 카테고리 카드 하단의 입력창에 이름을 입력하고 Enter(또는 "+" 버튼)로 그 카테고리에 항목을 추가합니다.
3. 카테고리 이름, 항목 이름, 그리고 화면 상단의 제목·부제목은 모두 ✎ 버튼으로 수정할 수 있습니다. 카테고리와 항목은 ✕ 버튼으로 삭제하며, 삭제 전에는 항상 "정말 제거하시겠습니까?" 확인 창이 뜹니다.
4. 각 항목 앞의 체크박스로 "이번 룰렛에 포함할지"를 정합니다. 체크된 항목은 카테고리가 달라도 모두 하나의 룰렛에 합쳐집니다 (예: 사업팀 김사원 + 홍보팀 박팀장 + 디자인팀 유사원).
5. 이름 옆의 **− ×1 +** 로 같은 사람을 룰렛에 **여러 번(최대 10칸)** 넣을 수 있습니다. ×3이면 룰렛에 그 사람 칸이 3개 생겨 당첨 확률도 3배가 되고, 칸들은 한데 몰리지 않도록 룰렛 곳곳에 고르게 흩어져 배치됩니다. 당첨되면 기록은 한 번만 쌓입니다.
6. "돌리기" 버튼 아래에는 지금 룰렛에 들어가 있는 사람이 `소속/이름` 형식으로 작게 표시됩니다 (여러 번 넣은 사람은 `×3`처럼 표시되고, 전체 칸 수도 함께 보입니다).
7. 카테고리 카드는 ⋮⋮ 손잡이를 드래그하거나 ◀▶ 버튼으로, 카드 안의 항목은 ⋮⋮ 손잡이를 드래그해 순서를 바꿀 수 있습니다. (터치 화면에서는 드래그가 동작하지 않아 손잡이를 숨깁니다.)
8. 서로 다른 사람이 2명 이상 들어가 있으면 "돌리기" 버튼이 활성화됩니다 (한 사람만 여러 칸 넣은 경우는 제외). 룰렛은 돌릴 때마다 4~6초 사이의 회전 시간과 기준 속도의 0.8~1.2배 사이의 회전 속도가 무작위로 정해집니다.
9. 회전하는 동안 포켓이 지나갈 때마다 째깍이는 소리가 점점 느려지고, 멈추면 색종이 효과와 짧은 팡파레가 재생됩니다. 결과는 화면 최상단 배너에 "카테고리 이름" 형식의 큰 글씨로 표시됩니다.
10. 화면은 항상 다크 테마로 고정되어 있습니다 (기기의 라이트/다크 설정과 무관).

## 당첨 횟수

- 각 항목 아래에 "최근 일주일/한달 내 당첨 횟수"가 표시됩니다. 룰렛이 멈출 때마다 당첨된 항목에 당첨 시각이 기록되고, **지금 시각 기준 최근 7일 / 28일(4주)** 안에 들어오는 기록만 집계됩니다.
- 집계는 "오늘 기준 며칠 전"으로 계산하므로 시간이 지나면 자동으로 줄어듭니다. 예를 들어 9월 7일에 당첨된 기록은 9월 14일까지는 일주일 횟수에 포함되고, 9월 15일이 되면 일주일 횟수에서 빠집니다 (28일 횟수에는 10월 5일까지 남습니다).
- 앱을 켜 둔 채로 날짜가 바뀌어도, 화면을 다시 볼 때(앱으로 돌아올 때)와 10분마다 횟수를 다시 계산해 최신 상태로 맞춥니다.
- 화면 오른쪽 위에 고정된 "당첨횟수 초기화" 버튼으로 모든 기록을 0회로 되돌릴 수 있습니다 (확인 창에서 "초기화"를 눌러야 실행됩니다).
- 바로 아래 "당첨횟수 복구" 버튼은 마지막 초기화 직전의 기록을 되돌립니다. 되돌릴 기록이 없으면 비활성화됩니다.

## 저장과 기기 간 공유

카테고리·항목·당첨 기록·제목 설정은 **브라우저의 localStorage**에 저장되어 새로고침해도 유지됩니다. 다만 이는 "그 브라우저 안"에만 저장되는 것이라, 다른 스마트폰이나 다른 브라우저에서 열면 당첨 기록이 보이지 않고 별도로 시작됩니다 — 서버가 없는 순수 정적 페이지이기 때문입니다.

기기 간에 데이터를 옮기는 **내보내기 / 가져오기** 기능도 있습니다. 구글 시트 동기화가 생기면서 지금은 화면에서 빼 두었지만 기능은 그대로 남아 있어, `index.html`에서 `export-btn`·`import-btn` 버튼의 `hidden`만 지우면 왼쪽 위에 다시 나타납니다.

- **내보내기**: 현재 카테고리·항목·당첨 기록·제목 설정을 `roulette-backup-YYYY-MM-DD.json` 파일로 바로 다운로드합니다.
- **가져오기**: 내보낸 `.json` 파일을 다른 기기·브라우저에서 선택하면 (덮어쓰기 확인 후) 현재 데이터를 그 파일 내용으로 교체합니다.

이 방식은 실시간 동기화는 아니고, 내보낸 시점의 스냅샷을 수동으로 옮기는 방식입니다. 여러 사람이 같은 기록을 자동으로 공유하려면 아래 "동료들과 당첨 기록 공유하기"를 사용하세요.

## 동료들과 당첨 기록 공유하기

구글 시트 하나를 공용 저장소로 쓰면, 같은 시트에 연결한 사람끼리 명단과 당첨 기록이 자동으로 공유됩니다. 서버를 따로 띄울 필요도, 비용도 없습니다. 누가 언제 걸렸는지는 시트에서 표로 바로 볼 수도 있습니다.

### 준비 (한 사람만, 약 5분)

1. [sheets.new](https://sheets.new) 로 빈 스프레드시트를 하나 만듭니다. 이름은 자유롭게 (예: `커피 룰렛 기록`).
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있던 `function myFunction() {}` 을 모두 지우고, 이 저장소의 **`sheet-sync.gs` 내용 전체**를 붙여넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누르고, 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
5. 아래 두 가지를 반드시 이렇게 맞춥니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르면 권한 승인 화면이 뜹니다. 본인 구글 계정을 고르고, "이 앱은 확인되지 않았습니다" 경고에서 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누릅니다. 본인이 방금 붙여넣은 스크립트라서 뜨는 경고입니다.
7. 마지막에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/...../exec`)을 복사합니다. 나중에 다시 찾으려면 **배포 → 배포 관리**에서 볼 수 있습니다.
   - ⚠️ 이 주소를 브라우저에서 열면 주소창이 `script.googleusercontent.com/macros/echo?...`로 바뀝니다. **그 바뀐 주소는 복사하지 마세요.** 한 번만 쓰이는 임시 주소라 기록이 저장되지 않습니다 (앱도 이 주소는 거절합니다).

### 연결

앱 화면 왼쪽 위 **동기화** 버튼을 누르고 위 URL을 붙여넣은 뒤 "연결"을 누릅니다.

- **처음 연결하는 사람**: 시트가 비어 있으므로 그 기기의 명단과 당첨 기록이 시트로 올라갑니다.
- **그다음 사람들**: 시트에 이미 내용이 있으므로, 확인 창에서 "불러오기"를 누르면 내 화면이 시트 내용으로 맞춰집니다. 동료에게는 같은 URL만 전달하면 됩니다.

연결되면 동기화 버튼에 초록색 점(●)이 표시됩니다. 빨간 점은 시트에 닿지 못했다는 뜻이고, 버튼에 마우스를 올리면 이유가 나옵니다.

### 연결한 뒤의 동작

- 룰렛이 멈추면 당첨 기록이 즉시 시트에 쌓이고, 다른 사람 화면에는 **30초 안에** 반영됩니다. 앱으로 돌아올 때도 즉시 한 번 확인합니다.
- 항목 추가·삭제·이름 변경·체크박스·제목 변경도 모두 공유됩니다. 이름을 바꾸면 그 사람의 과거 당첨 기록도 새 이름으로 함께 옮겨지므로 횟수가 끊기지 않습니다.
- **인터넷이 끊겨도** 룰렛은 그대로 돌아갑니다. 그동안의 당첨은 기기에 보관해 두었다가 연결이 돌아오면 자동으로 시트에 올립니다 (앱을 껐다 켜도 유지됩니다).
- **당첨횟수 초기화**를 누르면 시트의 기록이 `당첨기록_백업` 탭으로 옮겨지고 모두의 화면이 0회가 됩니다. **복구**를 누르면 되돌아옵니다.
- **연결 해제**를 눌러도 그때까지의 내용은 그 기기에 그대로 남습니다.

### 시트에는 이렇게 쌓입니다

| 탭 | 내용 |
| --- | --- |
| `당첨기록` | `시각 / 카테고리 / 이름` — 당첨될 때마다 한 줄씩 |
| `명단` | `카테고리 / 이름 / 룰렛 포함 / 넣은 횟수` — 시트에서 직접 고쳐도 앱에 반영됩니다 |
| `설정` | 제목·부제목 |
| `당첨기록_백업` | 초기화로 치워둔 기록 |

### 알아둘 점

- 이 URL을 아는 사람은 누구나 기록을 읽고 쓸 수 있습니다. 사내에서 커피 당번을 정하는 용도로는 충분하지만, 민감한 정보는 넣지 마세요.
- 두 사람이 거의 동시에 룰렛을 돌려도 당첨 기록은 둘 다 안전하게 쌓입니다. 다만 명단을 동시에 고치면 **나중에 저장한 쪽**이 남습니다.
- **"넣은 횟수"(여러 번 넣기)를 동료와 공유하려면 최신 `sheet-sync.gs`로 스크립트를 교체**해야 합니다. 예전 스크립트에서도 앱은 정상 동작하지만, 횟수는 각자 기기에만 저장됩니다.
- `sheet-sync.gs`를 나중에 수정했다면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**로 다시 배포해야 반영됩니다. URL은 그대로 유지됩니다.

## 모바일 지원

화면 크기와 비율에 맞춰 레이아웃이 자동으로 조정됩니다.

- **룰렛 크기**: 화면 너비와, 배너·제목 아래 남은 높이 중 작은 쪽에 맞춰집니다. 폰이 길쭉하든 짧든 룰렛과 "돌리기" 버튼이 첫 화면에 들어오도록 하고, 화면 해상도에 맞춰 다시 그려서 흐려지지 않습니다. (가로로 눕힌 폰처럼 높이가 아주 낮으면 최소 크기로 줄이고 스크롤합니다.)
- **카테고리 카드**: 옆으로 넘겨 보는 가로 스크롤입니다. 카드 폭은 화면에 맞춰 바뀌어(최대 260px), 항상 다음 카드가 조금 보이도록 해서 옆으로 넘길 수 있다는 걸 알 수 있고, 손을 떼면 카드가 화면 왼쪽에 맞춰 멈춥니다.
- **결과 문구**: 양쪽 모서리 버튼의 실제 폭을 재서 그만큼만 비워 두고, "사업팀 / 김사원"처럼 띄어쓰기 단위로 줄을 바꿉니다.
- **노치·상태 표시줄**: 노치가 있는 폰이나 홈 화면에 설치한 iOS 앱에서 상단 버튼과 배너가 상태 표시줄 밑으로 가려지지 않도록 안전 영역만큼 띄웁니다.

터치 환경에서는 버튼이 자동으로 더 크게 표시되고, 동작하지 않는 드래그 손잡이(⋮⋮)는 숨겨 이름 칸을 넓힙니다. 카테고리 순서는 ◀▶ 버튼으로 바꿀 수 있습니다.

스핀이 진행되는 동안에는 결과가 어긋나지 않도록 편집·삭제·포함 여부 변경이 잠시 잠깁니다.

### 홈 화면에 앱처럼 설치하기

이 저장소는 GitHub Pages로 배포되어 있습니다: **https://leesh0424.github.io/roulette/**

스마트폰에서 이 주소를 열고 "홈 화면에 추가"를 하면 진짜 앱처럼 설치됩니다 — 아이콘이 생기고, 주소창 없이 전체 화면으로 열리며, 오프라인에서도 실행됩니다.

- **Android(Chrome)**: 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"
- **iOS(Safari)**: 공유 버튼 → "홈 화면에 추가"

`main` 브랜치에 푸시하면 1~2분 안에 위 주소에 자동으로 반영됩니다.

`index.html`을 파일로 직접 열었을 때(주소창이 `file://`로 시작할 때)는 브라우저 보안 정책상 이 설치 기능과 오프라인 캐시(서비스 워커)가 동작하지 않습니다 — 이 경우에도 앱 자체는 정상적으로 동작하며, 단지 "설치" 절차만 웹 호스팅이 필요합니다.
