# 룰렛

항목을 입력하고 돌려서 무작위로 하나를 선택하는 간단한 웹 룰렛 앱입니다.

## 실행 방법

별도의 빌드 도구 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 사용법

1. 상단 카테고리 칩을 클릭해 룰렛을 돌릴 카테고리를 선택합니다. "+ 카테고리"로 새 카테고리를 추가하고, ✎/✕ 버튼으로 이름 수정·삭제를 할 수 있습니다.
2. 선택한 카테고리의 항목 입력창에 이름을 입력하고 Enter(또는 "추가" 버튼)로 목록에 추가합니다.
3. 각 항목도 ✎/✕ 버튼으로 이름 수정·삭제를 할 수 있습니다.
4. 카테고리 칩과 항목 목록은 ⋮⋮ 손잡이를 드래그해 순서를 바꿀 수 있습니다.
5. 항목이 2개 이상이면 "돌리기" 버튼이 활성화됩니다.
6. "돌리기"를 누르면 룰렛이 회전하고, 멈춘 위치의 항목이 색종이 효과와 짧은 팡파레 사운드와 함께 결과로 표시됩니다.

스핀이 진행되는 동안에는 결과가 어긋나지 않도록 카테고리/항목 편집이 잠시 잠깁니다.
