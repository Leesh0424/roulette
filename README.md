# 룰렛

항목을 입력하고 돌려서 무작위로 하나를 선택하는 간단한 웹 룰렛 앱입니다.

## 실행 방법

별도의 빌드 도구 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 사용법

1. 화면 아래쪽 "카테고리 보드"에서 모든 카테고리와 그 하위 항목을 한눈에 볼 수 있습니다. 각 카테고리는 하나의 카드(컬럼)로 표시되며, 맨 오른쪽 "+ 카테고리 추가" 카드로 새 카테고리를 만듭니다.
2. 각 카테고리 카드 하단의 입력창에 이름을 입력하고 Enter(또는 "+" 버튼)로 그 카테고리에 항목을 추가합니다.
3. 카테고리 이름과 항목 이름은 ✎ 버튼으로 수정할 수 있고, ✕ 버튼으로 삭제할 수 있습니다. 삭제 전에는 항상 "정말 제거하시겠습니까?" 확인 창이 뜨며, "제거"를 눌러야 실제로 삭제됩니다.
4. 각 항목 앞의 체크박스로 "이번 룰렛에 포함할지"를 정합니다. 체크된 항목은 카테고리가 달라도 모두 하나의 룰렛에 합쳐집니다 (예: 사업팀 김사원 + 홍보팀 박팀장 + 디자인팀 유사원). 현재 룰렛에 포함된 전체 목록은 화면 중앙의 "룰렛 적용 항목"에서 한눈에 확인하고 ✕로 바로 뺄 수 있습니다.
5. 카테고리 카드와 카드 안의 항목은 각각 ⋮⋮ 손잡이를 드래그해 순서를 바꿀 수 있습니다.
6. 포함된 항목이 2개 이상이면 "돌리기" 버튼이 활성화됩니다.
7. "돌리기"를 누르면 룰렛이 회전하면서 슬라이스가 지나갈 때마다 째깍거리는 소리가 점점 느려지고, 멈추면 색종이 효과와 짧은 팡파레 사운드가 재생됩니다. 결과는 화면 최상단에 "카테고리 이름" 형식의 큰 글씨로 표시됩니다.
8. 돌리기 버튼 옆의 스피커 아이콘으로 음소거를, 슬라이더로 전체 효과음/팡파레 음량을 조절할 수 있습니다.

스핀이 진행되는 동안에는 결과가 어긋나지 않도록 카테고리/항목 편집, 포함 여부 변경, 삭제가 잠시 잠깁니다.
